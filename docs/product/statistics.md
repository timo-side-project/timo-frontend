# 통계 (시간관 변화)

회고와 테스트로 쌓인 시간관점 카테고리별 점수가 이상적인 값에 얼마나 가까워지는지 보여줘서, 회고의 효과를 체감하게 한다.
개념·용어는 [product.md](../product.md) 참고.

코드에서 추론했고 기획 의도가 확정되지 않은 규칙은 `[확인 필요]`, 코드가 의도와 다르게 동작하는 것으로 보이는 부분은 맨 아래 "확인 필요 — 버그 의심"에 모은다.

## 규칙

### 캐릭터 선택

- 화면 제목은 "시간관 변화"다
- 상단에 카테고리별 캐릭터가 가로로 나열되고, 처음에는 첫 번째 캐릭터가 선택돼 있다
- 캐릭터를 누르면 그 카테고리의 그래프로 바뀐다

### 그래프

- 제목은 "[캐릭터 이름] 그래프"다
- 기간은 1주(기본) / 1달 / 3달 / 6달 / 1년 중에서 고른다
  - 기간은 오늘 0시 기준으로 거꾸로 센다 (예: 1주 = 7일 전부터)
- 1주·1달은 막대 그래프, 3달·6달·1년은 선 그래프로 보여준다
- 이상적 점수는 점선으로 표시한다. 이상적 점수 이상인 막대·점은 밝게 표시한다
- 데이터가 30개 이하일 때만 선 그래프에 점을 찍는다
- 가로축 라벨
  - 막대 그래프: 왼쪽 "1주 전" / "1달 전", 오른쪽 마지막 데이터 날짜("9월 16일")
  - 선 그래프: 날짜를 최대 5개 "9/16" 형식으로 표시
- 점수 데이터에는 테스트 결과와 회고 결과가 함께 들어간다
- [확인 필요] product.md의 "카테고리 분포·근접도 변화"와 달리, 실제로는 카테고리를 하나씩 골라서 그 점수 변화를 본다

### 이상치 근접 문구

- 선택한 기간의 가장 최근 근접률 값으로 문구를 정한다
  - 기간에 데이터가 없음 → "이 기간에는 회고 내역이 없어요. 다른 기간을 선택해 보세요!"
  - 근접률이 0이거나 없음 → "아직 이상치와의 거리가 좁혀지지 않았어요. 회고를 꾸준히 이어가 보세요!"
  - 가까워짐 → "회고를 통해서 N% 이상치에 가까워졌어요!"
  - 멀어짐 → "회고를 통해서 N% 이상치에 멀어졌어요."
- [확인 필요] "이상치에 멀어졌어요"(→ "이상치에서 멀어졌어요"?) 문구가 맞는지

### 새로고침

- 화면을 당겨서 새로고침하면 통계를 다시 불러온다

## 예외

- 기간에 데이터가 없음 → 그래프 자리에 "이 기간의 데이터가 없어요"
- 캐릭터 목록이 비어 있음 → "표시할 통계 데이터가 없습니다."
- 통계 불러오기 실패 → "시간관 변화 정보를 불러오지 못했어요." + 다시 시도

## 확인 필요 — 버그 의심

- **근접률이 0이면 가까워졌는지 여부와 상관없이 "아직 좁혀지지 않았어요"로 나온다.** 0이 "변화 없음"인지 "계산 불가"인지 백엔드 의미 확인 필요
