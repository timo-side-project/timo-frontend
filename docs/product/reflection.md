# 회고 · AI 피드백

사용자가 매일 시간관점 카테고리에 맞는 질문에 답하고, AI 피드백으로 자기 성향 변화를 확인하게 한다.
개념·용어는 [product.md](../product.md) 참고. 보상 해금 화면(`/reward`)과 통계(`/statistics`)는 각 기능 문서에서 다룬다.

- 코드에서 추론했고 기획 의도가 확정되지 않은 규칙은 `[확인 필요]`로 표시한다
- 코드가 의도와 다르게 동작하는 것으로 보이는 부분은 맨 아래 "확인 필요 — 버그 의심"에 모은다

## 규칙

### 홈

- 홈에는 오늘의 질문과, 그 질문의 시간관점 카테고리에 맞는 캐릭터가 보인다
- 오늘 회고를 **아직 안 썼으면** "다른 질문 받기" / "답변하기" 두 버튼이 보인다
- 오늘 회고를 **이미 썼으면** "나의 답변 보기" 버튼 하나만 보이고, 누르면 `/reflection/[id]`로 간다
- 오늘 회고 작성 여부를 불러오는 동안은 두 버튼 모두 비활성이다
- "다른 질문 받기"를 누르면 오늘의 질문이 새 질문으로 바뀐다
  - [확인 필요] 하루에 질문을 바꿀 수 있는 횟수 제한이 있는지 (프론트에는 제한 없음)
- 연속 기록일수가 정확히 1일인 사용자에게 서비스 피드백 모달("Timo서비스 이용은 어떠셨나요?")을 보여준다
  - 별점(0~5, 같은 별을 다시 누르면 0점)과 의견을 입력한다. 의견은 필수, 별점은 선택
  - "의견 보내기" 성공 → 모달 닫힘 + "답변이 제출되었습니다." 토스트
  - "다시 보지 않기"나 바깥을 누르면 닫힌다
  - 제출하거나 닫으면 같은 브라우저에서는 다시 뜨지 않는다
  - [확인 필요] 첫 회고 직후(연속 1일)에만 뜨는 게 기획 의도인지
- 알림 아이콘을 누르면 `/notification`으로 간다

### 회고 작성 (`/reflection`)

- 오늘의 질문을 불러온 뒤에만 답변을 입력할 수 있다
- 답변은 최대 3,000자다. 초과 입력은 받지 않는다
- 공백만 입력했거나 제출 중이면 "기록 완료" 버튼이 비활성이다
- 제출하면 답변 앞뒤 공백을 지우고 저장한다
- 저장 직후 AI 피드백 생성을 요청한다. 둘 다 성공해야 피드백 화면으로 간다
- 성공하면 "기록이 완료되었어요." 토스트와 함께 `/reflection/[id]/feedback`으로 이동한다
- 회고는 하루에 하나만 쓸 수 있다
  - [확인 필요] "하루"와 "오늘의 질문"이 바뀌는 기준 시각(한국 시간 자정인지)
- [확인 필요] 회고의 공개 여부(`isPublic`)를 사용자가 정하는 화면이 없다. product.md에는 "공개 여부를 토글해 그룹 내 공개를 결정한다"고 되어 있다

### AI 피드백 (`/reflection/[reflectionId]/feedback`)

- 피드백은 생성 대기(PENDING) → 생성 중(PROCESSING) → 완료(COMPLETED) 또는 실패(FAILED) 순서로 진행된다
- 생성이 끝날 때까지 "피드백 생성 중..." 상태를 보여주며 1초마다 다시 확인한다
- 완료되면 연속 기록 배지, 질문 카테고리의 캐릭터, 지수 변화, 피드백 내용을 보여준다
- 연속 기록 배지
  - 연속 기록일수가 1일 이하면 "첫 회고 달성!"
  - 2일 이상이면 "N일 연속 회고 중!"
- 지수 변화 문구 (예: 카테고리가 과거 부정일 때)
  - 변화가 0이면 "과거 부정 지수가 그대로예요."
  - 올랐으면 "과거 부정 지수가 0.2% 올랐어요.", 내려갔으면 "… 0.2% 내려갔어요." (소수점 한 자리)
  - 0보다 크고 0.1 미만이면 0.0%가 아니라 0.1%로 표시한다
- "완료"를 누르면 최근 해금된 보상이 있으면 `/reward`, 없으면 홈으로 간다
- "변화보기"를 누르면 `/statistics`로 간다

### 회고 상세 (`/reflection/[reflectionId]`)

- 내 질문, 답변, 카테고리 메시지, AI 피드백 내용을 보여준다. 배지는 "나의 회고"로 표시한다

## 예외

### 홈

- 질문 바꾸기 실패 → "새 질문을 가져오지 못했어요. 잠시 후 다시 시도해주세요." 토스트, 기존 질문 유지
- 서비스 피드백: 의견이 비어 있음 → 입력칸이 빨갛게 바뀌고 "의견을 남겨주세요."
- 서비스 피드백: 이미 제출함 (409) → 모달 닫힘 + "이미 피드백을 제출하셨습니다." 토스트
- 서비스 피드백: 그 밖의 제출 실패 → 모달 안에 "제출에 실패했습니다. 잠시 후 다시 시도해주세요."
- 로그인 정보 조회 실패 → `/login`
- 온보딩(ZTPI 테스트) 미완료 → `/ztpi-test`

### 회고 작성

- 오늘의 질문 불러오기 실패 → "오늘의 질문을 불러오지 못했어요." 에러 화면 + 다시 시도. 이때 "기록 완료" 버튼은 숨긴다
- 이미 오늘 회고를 씀 (409) → "오늘 회고는 이미 작성했어요." 토스트 + 홈으로
- 그 밖의 저장 실패 → "기록에 실패했어요. 잠시 후 다시 시도해주세요." 토스트, 작성 화면과 입력 내용 유지
- 회고는 저장됐는데 피드백 생성 요청 실패 → "피드백 생성에 실패했어요. 잠시 후 다시 시도해주세요." 토스트 + 홈으로
  - [확인 필요] 이 경우 피드백을 다시 요청할 방법이 있는지. 홈은 이미 "나의 답변 보기" 상태가 된다

### AI 피드백

- 10초가 지나도 생성이 안 끝남 → "피드백을 불러오지 못했어요" 에러 화면 + "홈으로 돌아가기"
  - [확인 필요] 10초가 기획 값인지, 타임아웃 뒤에 생성된 피드백은 어디서 보는지
- 피드백 실패(FAILED), 오늘 회고 조회 실패, 피드백 상세 조회 실패 → 같은 에러 화면
- "완료" 후 보상 조회 실패 → "보상 정보를 불러오지 못했어요." 토스트 + 홈으로

### 회고 상세

- 조회 실패 → "회고를 불러오는 데 실패했어요." 에러 화면 + 다시 시도
  - [확인 필요] 남의 회고 id나 없는 id로 들어왔을 때 기대 동작 (지금은 같은 에러 화면)

## 확인 필요 — 버그 의심

- **피드백 화면이 URL의 회고 id를 쓰지 않는다.** `/reflection/[id]/feedback`은 id와 상관없이 항상 "오늘 회고"의 피드백을 보여준다. 어제 회고 id로 들어와도 오늘 피드백이 보이고, 오늘 회고가 없으면 에러 화면이 뜬다.
  - "잘못된 페이지 주소입니다." 토스트 후 홈으로 보내는 컴포넌트(`InvalidFeedbackRedirect`)가 있지만 어디서도 쓰이지 않는다
- **점수 변화 조회만 실패해도 피드백 전체가 에러가 된다.** 피드백 내용은 이미 받았는데 지수 변화 조회가 실패하면 내용도 보여주지 않는다
