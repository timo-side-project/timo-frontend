# 캘린더

지금까지 쓴 회고를 날짜별로 돌아보고, 연속 기록을 확인해서 회고를 이어가게 한다.
개념·용어는 [product.md](../product.md) 참고.

코드에서 추론했고 기획 의도가 확정되지 않은 규칙은 `[확인 필요]`, 코드가 의도와 다르게 동작하는 것으로 보이는 부분은 맨 아래 "확인 필요 — 버그 의심"에 모은다.

## 규칙

### 연속 기록 배너

- 화면 상단에 "N일 연속 기록 중이에요!"가 보인다
- [확인 필요] 연속 기록이 0일일 때도 "0일 연속 기록 중이에요!"로 보인다. 문구가 맞는지

### 달력

- 처음에는 이번 달을 보여준다. 월은 "2026.09" 형식이다
- 이전 달 / 다음 달로 이동할 수 있다. 월을 바꾸면 선택한 날짜가 풀린다
- 이번 달 날짜만 보이고, 앞뒤 달 날짜 칸은 비어 있다
- 회고를 쓴 날은 그날 질문의 시간관점 카테고리 색으로 표시한다
  - 날짜는 서버가 준 회고 작성 시각(`reflectedAt`)의 앞 10자리(`yyyy-MM-dd`)로 정한다
  - [확인 필요] 작성 시각이 UTC로 오면 한국 시간 오전 0~9시에 쓴 회고가 전날 칸에 표시된다. 서버가 한국 시간으로 주는지
- 미래 날짜와 회고가 없는 날은 회색이다
- 선택한 날짜에 테두리가 생긴다. 선택한 날짜가 없으면 오늘에 테두리가 있다

### 요약 카드

- **날짜를 선택하지 않았을 때** (처음 들어왔을 때)
  - 오늘의 질문을 보여준다
  - 오늘 회고를 썼으면 답변을, 안 썼으면 "아직 답변하지 않았어요!"를 보여준다
  - 질문을 누르면 오늘 회고를 썼으면 `/reflection/[id]`, 안 썼으면 `/reflection`으로 간다
- **회고가 있는 날짜를 선택했을 때**
  - 그날 질문과 답변(최대 2줄)을 보여준다
  - 질문을 누르면 `/reflection/[id]`로 간다
- **회고가 없는 날짜를 선택했을 때**
  - "회고를 기록하지 않았어요 / 다른 날짜를 선택해 회고를 확인해 보세요."를 보여준다. 눌러도 이동하지 않는다
  - 단, 오늘을 선택했는데 오늘 회고가 없으면 날짜를 선택하지 않았을 때와 같다

### 새로고침

- 화면을 당겨서 새로고침하면 회고와 사용자 정보(연속 기록)를 다시 불러온다

## 예외

- 연속 기록, 월별 회고, 오늘의 질문, 오늘 회고 중 하나라도 불러오지 못함 → "캘린더 정보를 불러오지 못했어요." + "홈으로 돌아가기"

## 확인 필요 — 버그 의심

- **미래 날짜도 누를 수 있다.** 누르면 "회고를 기록하지 않았어요 / 다른 날짜를 선택해 회고를 확인해 보세요."가 나온다. 미래 날짜는 선택을 막아야 하는지
- **다음 달 이동에 제한이 없다.** 이번 달 이후로 계속 넘어갈 수 있다
