# 프로필 · 알림

내 캐릭터와 계정 정보를 확인하고, 닉네임·알림·계정을 관리한다. 받은 알림 목록을 확인한다.
개념·용어는 [product.md](../product.md) 참고. 테마 선택(`/profile/theme`)은 [reward.md](./reward.md)에서 다룬다.

코드에서 추론했고 기획 의도가 확정되지 않은 규칙은 `[확인 필요]`, 코드가 의도와 다르게 동작하는 것으로 보이는 부분은 맨 아래 "확인 필요 — 버그 의심"에 모은다.

## 규칙

### 마이페이지 (`/profile`)

- 제목은 "마이페이지", 우측 상단 테마 아이콘을 누르면 `/profile/theme`로 간다
- **요약**
  - 장착한 테마·펫이 있으면 테마 이미지 위에 펫을 겹쳐 보여주고, 없으면 내 카테고리 캐릭터를 보여준다
  - "[닉네임]님은 [과거부정형 등]이에요. / [캐릭터 이름]와 함께 시간을 기록하고 있어요!"
- **시간관 캐릭터 테스트**
  - "테스트 다시하기" → `/ztpi-test`
  - "지난 테스트결과 보기" → 가장 최근에 완료한 테스트 결과(`/ztpi/[id]?from=profile`)
- **개인정보**
  - "닉네임 변경" → `/profile/nickname`
  - "계정관리" 오른쪽에 가입한 방식("카카오 로그인" / "구글 로그인" / "네이버 로그인")이 보인다
- **알림**: 알림 수신 켜기/끄기, 알림 시간 변경 (아래)
- **계정**: 로그아웃, 탈퇴하기 (아래)

### 닉네임 변경 (`/profile/nickname`)

- 지금 닉네임이 입력된 상태로 시작한다
- "변경하기"를 누르면 앞뒤 공백을 지우고 저장한 뒤 `/profile`로 간다 (토스트 없음)
- 저장 중에는 버튼이 "변경 중..."으로 바뀌고 비활성이다
- [확인 필요] 닉네임 길이·허용 문자 제한이 프론트에 없다. 백엔드 제한이 있는지

### 알림 설정

- "알림 수신" 토글은 알림 예약이 등록돼 있으면 켜져 있다
- **켜기**
  - 브라우저 알림 권한을 받아 기기를 등록하고 알림을 예약한다
  - 알림 시간은 이 브라우저에서 마지막으로 정한 시간, 없으면 오전 9시다
  - 성공 → "알림이 설정되었어요." 토스트
- **끄기**
  - 성공 → "알림이 해제되었어요." 토스트
- 토글 처리 중에는 토글이 비활성이다
- **알림 시간 변경**
  - 알림이 꺼져 있거나 처리 중이면 비활성이다
  - 오른쪽에 현재 시간이 "09:00 AM" 형식으로 보인다. 정보가 없으면 "--:--"
  - 누르면 시간 선택 모달이 열린다. 분은 10분 단위로 고른다
  - "저장" 성공 → 모달 닫힘 + "알림 시간이 변경되었어요." 토스트 / "취소" → 모달 닫힘

### 로그아웃 · 탈퇴

- "로그아웃" → "로그아웃 되었어요." 토스트 + `/login`
- "탈퇴하기" → 확인 모달
  - "정말 떠나시나요? / 지금까지 남긴 회고와 기록이 모두 삭제돼요. / 삭제된 기록은 다시 복구할 수 없어요. / 그래도 탈퇴하시겠어요?"
  - "계속 기록하기" → 모달 닫힘
  - "탈퇴하기" → "탈퇴가 완료되었어요." 토스트 + `/login`
- 로그아웃·탈퇴 처리 중에는 두 메뉴 모두 비활성이고, 탈퇴 처리 중에는 모달을 닫을 수 없다

### 알림 목록 (`/notification`)

- 홈 우측 상단 알림 아이콘으로 들어온다. 제목은 "알림"
- 받은 알림을 최신순으로 보여준다. 알림마다 시간("9월 16일 14:05" 형식)과 제목이 보인다
- 알림의 X를 누르면 바로 목록에서 사라지고 읽음 처리된다
- "모두 읽기"를 누르면 전체가 바로 사라지고 모두 읽음 처리된다. 처리 중에는 비활성이다

## 예외

### 마이페이지

- 완료한 테스트 결과가 없음 → "지난 테스트 결과가 없어요." 토스트
- 사용자 카테고리를 알 수 없음 → "현재쾌락형" / 지금이 캐릭터로 표시

### 닉네임 변경

- 공백만 입력 → 입력칸이 빨갛게 바뀌고 "닉네임을 입력해주세요." (다시 입력하면 사라짐)
- 저장 실패 → "닉네임 변경에 실패했어요." 토스트

### 알림 설정

- 알림을 켤 수 없는 환경
  - 알림을 지원하지 않는 브라우저 → "아이폰은 Safari로 홈 화면에 추가한 앱에서만 알림을 지원해요." (아이폰이 아니어도 같은 문구)
  - 브라우저 알림 권한 거부 → "브라우저 알림 권한이 꺼져 있어요. 설정에서 권한을 허용해주세요."
  - 알림 설정값 누락 → "알림 설정값이 누락되어 있어요. 관리자에게 문의해주세요."
  - 그 밖 → "알림 권한이 없거나 지원되지 않는 브라우저예요."
- 켜기 실패 → "알림 설정에 실패했어요." / 끄기 실패 → "알림 해제에 실패했어요."
- 시간 저장 실패 → "알림 시간 저장에 실패했어요." (모달 유지)

### 로그아웃 · 탈퇴

- 로그아웃 실패 → "로그아웃에 실패했어요. 잠시 후 다시 시도해주세요."
- 탈퇴 실패 → "탈퇴에 실패했어요. 잠시 후 다시 시도해주세요." (모달 유지)

### 알림 목록

- 알림 없음 → "알림 내역이 비어있어요 / 새로운 소식이 도착하면 알려드릴게요"
- 하나 읽음 처리 실패 → "알림 삭제에 실패했어요. 잠시 후 다시 시도해주세요." + 목록 다시 불러오기
- 모두 읽기 실패 → "모든 알림 읽음 처리에 실패했어요. 잠시 후 다시 시도해주세요." + 목록 다시 불러오기

## 확인 필요 — 버그 의심

- **알림 목록 조회가 실패하면 "알림 내역이 비어있어요"로 보인다.** 오류와 알림 없음이 구분되지 않는다
- **테스트 기록을 불러오기 전에 "지난 테스트결과 보기"를 누르면 결과가 있어도 "지난 테스트 결과가 없어요."가 나온다**
- **"알림 삭제에 실패했어요"라는 문구가 실제 동작(읽음 처리)과 다르다**
- **알림을 껐다가 다시 켤 때 시간은 이 브라우저에 기억한 값을 쓴다.** 다른 기기나 다른 브라우저에서 다시 켜면 오전 9시로 돌아간다
