# 그룹 회고

혼자 쓰는 회고를 지인이나 같은 시간관점 사용자와 공유해서 계속 쓰게 만든다.
개념·용어는 [product.md](../product.md) 참고.

- **친구 그룹(FRIEND)**: 사용자가 만들고 초대 코드로 친구를 부른다
- **캐릭터 그룹(CHARACTER)**: 같은 시간관점 카테고리 사용자끼리 묶인다

코드에서 추론했고 기획 의도가 확정되지 않은 규칙은 `[확인 필요]`, 코드가 의도와 다르게 동작하는 것으로 보이는 부분은 맨 아래 "확인 필요 — 버그 의심"에 모은다.

## 규칙

### 그룹 목록 (`/groups`)

- 친구 / 캐릭터 탭으로 나눠 내가 속한 그룹만 보여준다. 처음 탭은 친구
- 캐릭터 탭의 그룹은 카테고리 순서로 정렬한다
- 탭에 들어오면 첫 번째 그룹이 선택되고, 그 그룹 멤버의 랭킹이 아래에 보인다
- 랭킹 정렬은 지속순(기본) / 최신순 / 날짜순 세 가지다
  - [확인 필요] "날짜순"의 실제 기준은 총 작성일수(`TOTAL`)다. 라벨이 맞는지
- 랭킹 항목마다 닉네임, 오늘 답변, 연속 기록일수가 보인다. 친구 그룹에서만 프로필 이미지가 보인다
- 오늘 회고를 쓴 멤버를 누르면 그 멤버의 오늘 회고(`/groups/[groupId]/reflections/[reflectionId]`)로 간다
- 화면을 당겨서 새로고침하면 그룹 데이터를 다시 불러온다
- [확인 필요] product.md의 "이번 달 가장 많이 쓴 단어" 랭킹은 main 코드에 아직 없다

### 그룹 생성 (`/groups/create`)

- 목록 우측 상단 + → "그룹 생성하기". 지금 보고 있는 탭의 종류로 만든다
- URL의 종류 값이 잘못됐으면 친구 그룹으로 만든다
- 그룹 이름은 필수(앞뒤 공백 제거), 대표 이미지는 선택이다
- 생성하면 "코드 생성 완료" 모달에 초대 코드를 보여준다
  - "공유하기": 기기 공유 기능이 있으면 초대 링크(`/groups?join=friend&code=…`)를 공유하고, 없으면 링크를 복사한 뒤 "초대 링크가 복사되었어요." 토스트
  - "완료"나 모달 닫기 → `/groups`
- [확인 필요] 캐릭터 탭에서도 그룹을 직접 만들 수 있다. 캐릭터 그룹을 사용자가 만드는 게 맞는지, 만들면 초대 코드가 필요한지

### 그룹 참여

- 목록 우측 상단 + → "그룹 참여하기" → "친구 코드 입력" 또는 "캐릭터 회고 그룹 참여"
- **친구 코드 참여**
  - 코드가 공백이거나 요청 중이면 "입력하기" 버튼이 비활성이다
  - 초대 링크로 들어오면 코드 입력칸이 미리 채워진다
  - 성공 → `/groups` + "그룹에 참여했어요." 토스트
- **캐릭터 그룹 참여**
  - 확인 모달("내 캐릭터 회고 그룹에 참여하시겠어요?")에서 "참여하기"를 눌러야 참여한다
  - 요청 중에는 "참여하기" / "취소하기" 모두 비활성이다
  - 성공 → `/groups` + "캐릭터 그룹에 참여했어요." 토스트
- 참여 모달을 닫거나 "취소하기"를 누르면 `/groups`로 돌아간다

### 그룹 관리 (친구 그룹만)

- 친구 탭에서 그룹을 길게 누르면 메뉴가 열린다. Esc나 바깥을 누르면 닫힌다
- 그룹을 만든 사람(OWNER)에게는 "그룹 삭제하기", 멤버(MEMBER)에게는 "그룹 나가기"가 보인다. 둘 다 확인 모달("…을 삭제하시겠습니까?" / "…을 나가시겠습니까?")을 거친다
- "그룹 수정하기" → `/groups/[id]/edit`에서 이름과 대표 이미지를 바꾼다
  - 이미지를 새로 고르지 않으면 기존 이미지를 유지한다
  - 성공하면 "그룹 수정 완료" 모달 → `/groups`
- [확인 필요] 캐릭터 그룹은 길게 누르기 메뉴가 없어 나갈 수 없다. 한 번 참여하면 못 나가는 게 맞는지
- [확인 필요] product.md의 "그룹 생성자의 멤버 관리"에 해당하는 화면이 코드에 없다

### 친구 회고 (`/groups/[groupId]/reflections/[reflectionId]`)

- 그룹 멤버의 오늘 회고를 보여준다. 질문, 답변, 카테고리 메시지가 보이고 배지는 "[닉네임]의 회고"로 표시한다
- 친구 회고에서는 **AI 피드백 내용을 보여주지 않는다**
- 뒤로가기는 이전 화면으로, 이전 기록이 없으면 홈으로 간다
- [확인 필요] 랭킹에서 멤버를 누를 때 프론트는 회고 공개 여부(`isPublic`)를 확인하지 않는다. 비공개 회고의 답변을 백엔드가 비워서 내려주는지, 프론트에서 막아야 하는지

### 좋아요 · 댓글

- 좋아요를 누르면 결과를 기다리지 않고 바로 상태와 개수를 바꾼다. 개수는 0 아래로 내려가지 않는다
- 댓글 버튼을 누르면 댓글 시트가 열린다. 바깥이나 Esc로 닫고, 닫으면 입력 중이던 내용과 수정 상태를 버린다
- 공백만 입력하면 댓글 전송 버튼이 비활성이다. 전송에 성공하면 입력칸을 비운다
- 내가 쓴 댓글에만 "수정" / "삭제"가 보인다
  - 수정은 그 자리에서 편집 → "저장" / "취소". 공백으로는 저장되지 않는다

## 예외

### 그룹 목록

- 친구 탭에 그룹 없음 → "아직 참여 중인 그룹이 없어요 / 그룹을 만들고 친구들을 초대해보세요"
- 캐릭터 탭에 그룹 없음 → 같은 문구
- 랭킹에 멤버 없음 → "아직 함께하는 멤버가 없어요" (친구 그룹이면 "친구를 초대하고 함께 기록해보세요" 추가)
- 랭킹 조회 실패 → "친구 리스트를 불러오지 못했어요." (다시 시도 버튼 없음)
  - [확인 필요] 다시 시도 버튼이 없는 게 의도인지
- 오늘 회고를 안 쓴 멤버를 누름 → "아직 회고를 작성하지 않았어요." 토스트, 이동 안 함
- 답변은 있는데 회고 id가 없는 멤버를 누름 → 아무 반응 없음 (토스트 없음)

### 그룹 생성 · 수정

- 이름이 공백 → 제출해도 아무 일도 없다
  - [확인 필요] 안내 문구 없이 무반응인 게 의도인지
- 이미지 업로드나 생성 실패 → "그룹 생성에 실패했어요." 토스트
- 수정 실패 → "그룹 수정에 실패했어요." 토스트
- 내 그룹 목록에 없는 id로 수정 페이지 진입 / id가 숫자가 아님 → 404
- 공유 실패 → "공유에 실패했어요." / 복사 실패 → "초대 링크 복사에 실패했어요." (사용자가 공유를 취소하면 토스트 없음)

### 그룹 참여

- 친구 코드: 없는 코드(404) → 모달 안에 "그룹을 찾을 수 없어요"
- 친구 코드: 이미 참여한 그룹(409) → 모달 안에 "이미 참여한 그룹이에요"
- 친구 코드: 네트워크 오류 → "네트워크 오류가 발생했습니다. 다시 시도해주세요."
- 에러 문구는 코드를 다시 입력하면 사라진다
- 캐릭터 그룹: 시간관점 미설정(400) → `/groups` + "캐릭터 유형이 설정되지 않았어요. ZTPI 테스트를 먼저 해주세요."
- 캐릭터 그룹: 이미 참여(409) → `/groups` + "이미 캐릭터 그룹에 참여했어요."
- 캐릭터 그룹: 그 밖의 실패 → "그룹 참여 중 오류가 발생했습니다. 다시 시도해주세요." (모달 유지)

### 친구 회고

- groupId / reflectionId가 양의 정수가 아님 → 404
- 조회 실패 → "회고를 불러오는 데 실패했어요." + 다시 시도
- [확인 필요] 내가 속하지 않은 그룹이나 다른 그룹의 회고 id로 직접 들어왔을 때 기대 동작

### 좋아요 · 댓글

- 댓글이 없음 → 댓글 시트에 "첫 번째 댓글을 작성해주세요"
- 좋아요 실패 → 누르기 전 상태와 개수로 되돌린다 (토스트 없음)
- 댓글 작성 / 수정 / 삭제 실패 → 각각 "댓글 작성에 실패했어요" / "댓글 수정에 실패했어요" / "댓글 삭제에 실패했어요" 토스트

## 확인 필요 — 버그 의심

- **멤버에게도 "그룹 수정하기"가 보인다.** 삭제/나가기는 역할에 따라 나뉘지만 수정 메뉴는 역할과 상관없이 보인다. 멤버가 수정할 수 있는 게 맞는지, 백엔드에서 막히는지
- **그룹 삭제/나가기 실패 시 아무 반응이 없다.** 확인 모달이 닫히지 않고 토스트도 없다
- **친구 코드 참여에서 404·409가 아닌 오류 응답이 오면 에러 문구가 비어서 아무것도 안 보인다.**
