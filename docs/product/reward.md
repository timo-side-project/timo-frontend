# 보상 · 테마 커스터마이징

회고를 꾸준히 쓰면 테마와 펫을 해금해 주고, 캐릭터를 꾸미게 해서 회고를 계속할 동기를 만든다.
개념·용어는 [product.md](../product.md) 참고.

- **테마(THEME)**: 캐릭터 배경 이미지
- **펫(DECORATION)**: 캐릭터 옆에 붙는 장식

코드에서 추론했고 기획 의도가 확정되지 않은 규칙은 `[확인 필요]`, 코드가 의도와 다르게 동작하는 것으로 보이는 부분은 맨 아래 "확인 필요 — 버그 의심"에 모은다.

## 규칙

### 해금 조건

- 해금 조건은 두 종류다: 누적 회고 횟수(`TOTAL_COUNT`) / 연속 회고 일수(`STREAK_COUNT`). 조건 값은 서버에서 받는다
- [확인 필요] product.md의 해금 기준(학교 5회 / 놀이터공원 10회 / 수영장 15회 / 집 20회 / 우주 30회, 펫은 연속 30회)은 프론트 코드에 없다. 백엔드 값과 일치하는지
- [확인 필요] product.md의 "연속 실패 시 펫 사라짐"은 프론트에 처리가 없다. 백엔드에서 해금 상태를 되돌리는지

### 보상 획득 (`/reward`)

- 회고 피드백 화면에서 "완료"를 눌렀을 때 최근 해금된 보상이 있으면 들어온다 ([reflection.md](./reflection.md))
- 해금된 보상을 하나씩 순서대로 보여준다. 테마는 항상 마지막에 보여준다
- 보상마다 획득 화면을 보여준다
  - 배지: 누적 조건이면 "회고 N회 달성!", 연속 조건이면 "N일 연속 회고 달성!"
  - 문구: 테마면 "[테마 이름]를 획득했습니다!", 펫이면 "나의 캐릭터 펫을 획득했습니다!"
  - 버튼: "바로 적용하기" / "저장하기"
- "바로 적용하기" → 장착 후 "[이름] 적용 완료" 모달 (이미지 포함)
- "저장하기" → 장착하지 않고 "[이름] 저장 완료" 모달
- 모달에서 "완료"를 누르면 다음 보상으로, 마지막 보상이면 홈으로 간다
- 마지막 보상이 테마이고 "저장하기"를 골랐으면 모달에 "보러가기" 링크가 보이고, 누르면 `/profile/theme`로 간다
- [확인 필요] 한 번 본 보상이 다음에 다시 "최근 해금"으로 나오지 않는지 (백엔드 처리)

### 테마 선택 (`/profile/theme`)

- 프로필 우측 상단 테마 아이콘으로 들어온다. 제목은 "테마 선택하기"
- 상단 미리보기에 캐릭터 모습이 보인다
  - 새로 고른 테마 → 없으면 지금 장착한 테마 → 없으면 내 카테고리의 기본 캐릭터 순서로 보여준다
  - 펫도 같은 방식으로 겹쳐서 보여준다
- 아래에 "테마" 목록과 "펫" 목록이 보인다. 지금 장착한 항목이 선택된 상태로 표시된다
- 잠긴 항목은 흐리게 보이고 자물쇠가 표시되며 누를 수 없다
- 항목을 누르면 선택되고 미리보기가 바뀐다. 선택한 항목을 다시 누르면 선택이 풀린다
- 우측 상단 저장 아이콘을 누르면 새로 고른 테마·펫을 장착한다
  - 새로 고른 것이 없으면 아무 일도 없다
  - 성공하면 "나의 캐릭터 테마 적용 완료" 모달 → "보러가기"를 누르면 홈으로 간다

## 예외

### 보상 획득

- 보여줄 보상이 없음(직접 주소로 들어온 경우 포함) → 홈으로 이동
- 적용 실패 → "적용에 실패했어요." 토스트, 획득 화면 유지
- 피드백 화면에서 보상 확인 실패 → "보상 정보를 불러오지 못했어요." 토스트 + 홈

### 테마 선택

- 목록 불러오기 실패 → "테마 목록을 불러오지 못했어요" / "펫 목록을 불러오지 못했어요"
- 목록이 비어 있음 → "적용 가능한 테마가 없어요" / "적용 가능한 펫이 없어요"
- 테마·펫 중 하나라도 장착 실패 → "일부 적용에 실패했어요. 다시 시도해 주세요." 토스트

## 확인 필요 — 버그 의심

- **획득 문구의 조사가 "를"로 고정돼 있다.** 받침이 있는 테마 이름이면 "수영장를 획득했습니다!", "집를 획득했습니다!"처럼 틀린다
- **장착을 해제할 방법이 없다.** 장착한 항목을 다시 눌러 선택을 풀어도 장착 항목이 다시 선택된 것으로 보이고, 저장해도 해제되지 않는다
- **펫만 바꿔도 완료 모달 제목이 "나의 캐릭터 테마 적용 완료"다**
- **보상 목록 조회가 실패하면 안내 없이 홈으로 이동한다.** 보상이 없는 경우와 구분되지 않는다
