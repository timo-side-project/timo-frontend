# ZTPI 테스트 · 캐릭터

ZTPI 테스트로 사용자의 시간관점 카테고리와 캐릭터를 정한다. 온보딩의 필수 단계이고, 결과가 질문·캐릭터·통계의 기준이 된다.
개념·용어(카테고리, 캐릭터 이름)는 [product.md](../product.md) 참고.

코드에서 추론했고 기획 의도가 확정되지 않은 규칙은 `[확인 필요]`, 코드가 의도와 다르게 동작하는 것으로 보이는 부분은 맨 아래 "확인 필요 — 버그 의심"에 모은다.

## 규칙

### 테스트 진행 (`/ztpi-test`)

- 들어오면 ZTPI-15 테스트를 자동으로 시작한다. 진행 중인 기록이 있으면 이어서 한다
  - 이어서 할 때 "임시 저장된 테스트 기록을 불러왔어요." 토스트
  - 이미 답한 문항 수만큼 건너뛴 다음 문항부터 보여준다
- 문항마다 5단계 중 하나를 고른다: 전혀 그렇지 않아요 / 그렇지 않은 편이에요 / 보통이에요 / 그런 편이에요 / 매우 그래요
- 상단 진행 바와 "STEP 01" 형식의 문항 번호가 보인다
- 답을 고르기 전에는 "다음" 버튼이 비활성이다
- "다음"을 누르면 답을 저장하고 다음 문항으로 넘어간다
  - 처음 답한 문항은 새로 저장, 이미 답한 문항에서 답을 바꿨으면 수정, 그대로면 저장 없이 이동
  - 다음 문항에 이미 답이 있으면 그 답이 선택된 상태로 보인다
- "이전"을 누르면 이전 문항으로 돌아가고 저장했던 답이 선택돼 있다. 첫 문항에서는 비활성이다
- 마지막 문항에서는 버튼이 "완료"로 바뀐다. 누르면 답을 저장하고 테스트를 완료한 뒤 `/ztpi-test/complete`로 간다
- 완료 처리 중에는 "완료" 버튼이 비활성이다
- 뒤로가기는 이전 화면으로, 이전 기록이 없으면 홈으로 간다
- [확인 필요] 테스트를 완료하면 백엔드에서 온보딩 완료(`isOnboarded: true`)와 사용자 카테고리가 갱신되는지

### 완료 화면 (`/ztpi-test/complete`)

- "테스트 완료! / 나의 시간관은 무엇일까요?" 문구와 캐릭터 애니메이션이 보인다
- "결과 확인하기"를 누르면 결과 화면(`/ztpi/[id]?from=test`)으로 간다

### 결과 화면 (`/ztpi/[ztpiTestId]`)

- "나의 시간관 / 당신의 캐릭터는 [성향] [캐릭터 이름]에요!"와 설명, 결과 캐릭터 이미지를 보여준다
- 5개 카테고리별 점수 막대 그래프를 보여준다
  - 막대는 내 점수(5점 만점), 빛나는 점은 이상적 수치, 점들을 선으로 잇는다
  - 막대 아래에 캐릭터 이미지와 카테고리 이름(예: "과거긍정", "미래지향")이 보인다
- "완료"를 누르면 프로필에서 들어온 경우(`from=profile`) `/profile`, 그 밖에는 홈으로 간다
- "다른 캐릭터 알아보기"를 누르면 `/characters`로 간다
- 프로필의 "테스트 다시하기"는 `/ztpi-test`, "지난 테스트결과 보기"는 가장 최근 완료한 결과로 온다 ([profile.md](./profile.md))

### 캐릭터 소개 (`/characters`)

- "다른 캐릭터 알아보기" 제목으로 5개 캐릭터를 목록으로 보여준다. 캐릭터 정보는 서버에서 받는다
- 캐릭터를 누르면 펼쳐져서 "성향"과 "설명"이 보인다. 여러 개를 동시에 펼칠 수 있고, 다시 누르면 접힌다
- [확인 필요] product.md에는 "캐릭터를 확인/선택할 수 있다"고 되어 있지만 선택 기능은 없고 보기만 가능하다

## 예외

### 테스트 진행

- 테스트 목록 불러오기 실패 → "테스트를 불러오지 못했어요." + 다시 시도
- ZTPI-15 테스트가 목록에 없음 → "테스트 정보를 찾을 수 없어요." + 다시 시도
- 테스트 시작 실패 → "테스트 시작을 실패했어요." (다시 시도 버튼 없음)
- 문항 불러오기 실패 → "테스트 문항을 불러오지 못했어요." + 다시 시도

### 결과 화면

- 결과 불러오기 실패 → "테스트 결과를 불러오지 못했어요." + 다시 시도
- [확인 필요] 남의 결과 id나 없는 id로 들어왔을 때 기대 동작 (지금은 같은 에러 화면)

## 확인 필요 — 버그 의심

- **답 저장이나 테스트 완료가 실패해도 아무 반응이 없다.** 토스트나 에러 문구 없이 같은 문항에 머문다
- **완료 화면에 결과 id 없이 들어오면 "결과 확인하기"가 `/ztpi/undefined`로 이동한다**
- **캐릭터 목록 조회가 실패하면 캐릭터 화면 전용 에러 화면이 없다.** 앱 전체 오류 화면으로 넘어간다
- **테스트 시작 실패 화면에만 다시 시도 버튼이 없다.** 다른 오류 화면과 다르다
